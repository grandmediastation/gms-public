# Grand Media Station — Feedback & Roadmap

**Grand Media Station (GMS)** is a desktop app for Windows and Linux that
organizes your media library: smart renaming, library management, on-device
AI subtitle generation, transcoding, and media-server integration — with
every change tracked and undoable. Your library never leaves your machine.

- 🌐 Website & download: [grandmediastation.com](https://grandmediastation.com)
- 🗺️ Roadmap: [ROADMAP.md](ROADMAP.md)

This repo is the **public feedback home** for GMS: bug reports, feature
requests, and the roadmap live here so everyone can see what's known,
what's planned, and what the community wants most.

## Report a bug 🐛

[Open a bug report](https://github.com/grandmediastation/gms-public/issues/new?template=bug_report.yml)
for anything broken, wrong, or confusing in the app. Before filing:

1. Search existing issues — if it's already reported, add a 👍 and any
   extra details as a comment.
2. Include your app version and OS (the template asks).

You can also open the bug template straight from the app:
**Settings → About → Report a bug** (it pre-fills your version + OS).

## Request a feature 💡 (and vote!)

[Open a feature request](https://github.com/grandmediastation/gms-public/issues/new?template=feature_request.yml)
— or better, check the [existing requests](https://github.com/grandmediastation/gms-public/issues?q=is%3Aissue+label%3Aenhancement)
and **👍 the ones you want**. Votes are a real input: the roadmap's
"Proposed" section is ranked by them.

Labels you'll see:

| Label | Meaning |
|---|---|
| `planned` | On the roadmap — it's happening. |
| `under-consideration` | Being evaluated; votes and use-cases help. |
| `shipped` | Released — the issue notes which version. |

## When to use in-app support instead 🔒

Some things don't belong in a public issue. Use **in-app support**
(Settings → Support) when it's about *your* setup:

- License, activation, or trial questions
- Problems specific to your machine, library layout, or media server
- Anything you'd rather not post publicly (logs, file paths)

Billing questions are handled through the customer portal linked from
your purchase receipt.

## What this repo is not

- Not the source code — GMS is a commercial desktop app; this repo hosts
  feedback and the roadmap.
- Not a support queue — public issues are triaged best-effort; private
  setup help goes through in-app support.

See [CONTRIBUTING.md](CONTRIBUTING.md) for issue etiquette.
